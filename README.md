# 行知学园 · 大学院生物／化学

网站：https://daigakuin.coach-ai-assist.com/

保留原网站的课程介绍、师资、学生、升学经验、研究室查询和四种语言，移除 AI 择校栏目，新增「每日研究」与自动更新的数据源。

## 数据来源与更新

| 内容 | 来源 | 频率 |
| --- | --- | --- |
| 合格榜 | 指定 Google Drive 文件夹与服务器 `Documents/合格榜` 中的海报 | 每小时检查 |
| 课程表 | 指定 Google 表格的「生物」「化学」工作表 | 每小时检查；展示周期每半年切换 |
| 在籍学生 | 两份指定学生表的「在籍学生信息表（仅查看）」 | 每小时检查，仅发布人数与出身校汇总 |
| 出愿信息 | 原有 100 个专攻对应的大学官方页面和募集要项 | 每天核查；失败来源每小时重试 |
| 每日研究 | Europe PMC / PubMed 收录的生物、生化、化学、AI 生命科学期刊论文 | 每个日本日期最多新增 3 篇，保留历史并去重 |
| 研究室目录 | 大学与研究室官方网站、当前教员目录 | 人工核查后重建；卡片显示核查日期 |

课表按用户指定的初次排课表同步，源快照保留历史记录，网页仅展示东京日期所属的当前半年：4—9月或10月—次年3月。每年4月1日、10月1日自动切换，取消年度选择，按科目名分组并在组内按日期、时间排序，保留原班期名称。页面打开期间每分钟、恢复前台或返回页面时检查半年变化，切换后重新获取课表，失败时保留提示并每分钟重试；下一期无课程时显示待更新提示，不回退到旧课表。源表仍每小时检查，以便新排课程及时出现。原表不记录后续调课；网站已标明这一限制，仅导出课程、日期、时间、课次、内容和授课形式，不发布教师内部备注、录制要求等列。课表页面不展示原表入口；读取失败时显示提示并自动重试，不恢复旧版静态内容。

出愿页面只展示大学官网通知、募集要项链接、来源核查日期和未过期的出愿日程，支持大学／专攻搜索及生物／化学筛选。已移除旧院校资料卡、考试要求、材料清单、往年时间线和考试日历，旧入口转到官网信息页。`config/admissions_baseline.json` 与 `applications.json` 仅保留100个专攻的名称、分类和官网来源等目录信息，自动更新不会再发布旧考试要求或旧日程。日期提取不猜年份、不把考试日当出愿日，也不把不同专攻、招生方式或批次合并；截止日当天仍保留。页面失效、证书错误、PDF解析失败时保留最近成功读取的官网信息并标明状态，网页无法读取更新快照时仍提供官网入口。迁移后的官方地址维护于 `config/official_sources.json`。

论文条目保留原文标题、期刊、发表日期、收录日期和论文链接，不生成未经原文支持的研究结论。排除预印本、综述、撤稿和未来发表日期。来源不可用或没有合适新论文时保留已有条目。

研究室目录按研究领域组织，与「每日研究」论文更新分开。2026-11-12核查版包含21所大学、71个代表性研究室：生物16个领域36个研究室，化学15个领域35个研究室。各条保留官方日文名称、负责人、四语言主题与简介、关键词和官方出处，不推断招生名额。目录是代表性导览，不声称覆盖日本全部研究室；旧目录的错配或已退休负责人不直接沿用。大阪公立大学核查时的官网故障在该卡片来源详情中标明。

研究室数据与出处维护于 `config/research_labs.json`，领域按钮与卡片由 `scripts/build_research_directory.py` 生成到 `index.html`，不依赖运行时下载 JSON。修改数据后执行 `python3 scripts/build_research_directory.py`；使用 `--check` 可核对静态页面是否与目录一致。搜索覆盖全目录的四语言内容及大学别名，生物、化学分别记住上次选择的领域。大学名称保留官网原名，可用中文、繁体或英文大学名搜索。

合格榜按原文件内容校验去重，生成适合网页的 WebP 图片，保留原始海报不修改。无法确定年度的海报显示「未分年度」。本任务已完成本地与网盘的合并；网站的定时任务只读取这两个来源，不删除或改写原文件。

合格榜支持「生物」「化学」「AI科研背景提升」分类。带电路与网络图案、标注 AI 科研背景提升项目的两张2027年度海报，已按用户确认归入本地与网盘的 `2027年度/AI科研背景提升/`。同步器识别该目录并发布 `ai-research` 分类；以后放入该目录的海报会随每小时更新显示在同一分类。

课程介绍中的生物、化学年度计划取自《【25年宣传册】行知学园理科大学院》PDF 第16、18页的原生图片，保留夏季／冬季入试标注和底部说明。`images/{bio,chem}-annual-plan-hd` 提供4050×1080像素的无损 WebP 和 PNG，点击图表或下方链接可打开高清 PNG 放大阅读。

在籍统计纳入「在读」「直考在读」「待毕业」，排除「休学」及已毕业、退学、结业等状态。服务器仅读取学籍番号、状态、出身学校三列，在内存中按学籍番号去重，使用明确的学校别名映射合并同校写法。公开的 `students_data.json` 仅含总人数、科目人数、全体出身校人数、未填写人数和核查时间，不含逐人记录或源表链接；不提供科目与学校的交叉明细。任何一份表读取失败、字段变化或状态无法识别时，保留上次完整统计，网页保留原核查时间。源表配置存于服务器网站目录下的私有 `同步私有配置/students.json`，不进入 Git 仓库；迁移服务器时需单独配置。

## 服务器运行

同步环境为 Python 3.12；另需系统 `pdftotext`、Git 和已登录的 GitHub CLI。

```bash
cd /home/admin-coach-ai/Documents/大学院生化网页/github
../.sync-venv/bin/python -m pip install -r requirements-sync.txt
../.sync-venv/bin/python scripts/test_sync.py
../.sync-venv/bin/python scripts/sync_data.py
../.sync-venv/bin/python scripts/validate_data.py
../.sync-venv/bin/python scripts/sync_and_publish.py
```

Google 凭据从服务器既有 `~/.config/coach-google-sheets/` 中读取并在内存刷新：课表使用 `token.json`，网盘只读使用 `inventory_drive_readonly_token.json`。凭据不进入代码、公开 JSON 或 GitHub。私有运行日志、缓存和锁放在被 Git 忽略的 `.sync-state/`。

`deploy/` 提供用户级 systemd service/timer。每小时日本时间第 17 分钟（加最多 60 秒错峰）执行；服务器需保持开机联网。启用 `Persistent=true` 可在恢复运行时补跑，用户开启 linger 后不依赖交互登录。

```bash
systemctl --user status daigakuin-info-update.timer
systemctl --user start daigakuin-info-update.service
journalctl --user -u daigakuin-info-update.service -n 80 --no-pager
```

发布器使用锁避免重叠执行，仅暂存六个公开 JSON 和海报图片。有未提交的源代码改动或未经发布器识别的本地提交时停止；不会自动发布手工修改。同步后校验、提交并推送到 `main`，沿用 GitHub Pages 的 `main /` 发布设置。没有内容变化则不新建提交。推送失败会保留本地提交重试；远端变动仅对发布器自己的数据提交尝试 rebase，冲突停止，不强制推送。任务日志会显示失败原因。

推送成功后，从对应提交复制公开网站文件到同目录下的 `网页文件/`，以保持本地网页副本与已发布代码一致；保留既有备份和其他文件。

## 校验

`scripts/test_sync.py` 覆盖日期不跨年猜测、旧出愿字段排除、截止日边界、课表字段白名单、论文日期／类型和官网域名边界。
`scripts/test_students.py` 使用虚构记录验证在籍口径、去重、同校合并、缺失学校、公开字段白名单及单一来源失败时保留完整汇总。
`scripts/validate_data.py` 校验六个快照及海报引用。
`scripts/check_browser.py` 使用系统 Chrome 和 Python Playwright 验证四种语言、导航、筛选、弹窗、手机布局及单一数据源失败时的回退，退出时关闭临时预览服务器。浏览器校验额外依赖 `playwright`。

`scripts/check_schedule.py` 验证当前半年课程逐条一致、东京日期的4月／10月边界、跨年与闰日、页面自动切换和重新取数、失败重试，以及科目分组、搜索、四语和手机显示。

`scripts/check_research.py` 验证研究目录的全部领域、大学与关键词搜索、空结果、四语言、分类记忆及手机布局。
